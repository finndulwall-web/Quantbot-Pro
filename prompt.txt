### SECTION 2: DATA INGESTION (core/data.py)
1. Use `ccxt` for crypto data (Binance). Fetch 1-hour OHLCV data.
2. Use `yfinance` for stocks. Fetch 1-hour data.
3. Implement a caching layer (using `sqlite3`) so we don't hit rate limits and don't hold all historical data in RAM.
4. Handle missing candles, API timeouts, and rate limits gracefully. If a fetch fails, retry 3 times with exponential backoff.
5. Clean the data: remove NaNs, forward-fill missing volume, and ensure the index is a proper datetime object.

### SECTION 3: TECHNICAL INDICATORS (core/indicators.py)
Write pure Python/Pandas functions for the following. Do not use `TA-Lib`. Write the math from scratch.
1. EMA (Exponential Moving Average) for 20, 50, and 200 periods.
2. RSI (Relative Strength Index) for 14 periods.
3. MACD (Moving Average Convergence Divergence) with 12, 26, 9.
4. ATR (Average True Range) for 14 periods.
5. Bollinger Bands (20 period, 2 standard deviations).
6. VWAP (Volume Weighted Average Price) resetting daily.

### SECTION 4: THE STRATEGY ENGINE (core/strategy.py)
1. Define a "Signal" data class.
2. Entry Logic (Long Only):
   - Trigger A: RSI < 30 AND price is above EMA 200.
   - Trigger B: MACD crosses above signal line AND price > EMA 50 AND volume is 1.5x the 20-period average.
3. Exit Logic:
   - Take Profit: 2x ATR.
   - Stop Loss: 1x ATR.
   - Trailing Stop: Once profit is > 1x ATR, move stop loss to breakeven.
4. Add a "Market Regime" filter: If EMA 50 is below EMA 200, do not take long trades.

### SECTION 5: RISK MANAGEMENT (core/risk.py)
1. Account Balance: Start with 50,000 LKR (converted to USDT internally).
2. Risk per trade: 1% of total portfolio value.
3. Position Sizing Math: `Position Size = (Account Balance * 0.01) / (Entry Price - Stop Loss)`.
4. Max concurrent trades: 3. Max portfolio heat: 3%.

### SECTION 6: THE AI BRAIN (core/llm_brain.py)
1. When a signal fires, collect the last 5 candles, current RSI, MACD, and ATR.
2. Use the `openai` Python package, pointing to `base_url="https://integrate.api.nvidia.com/v1"`.
3. Use the model `nvidia/nemotron-3-ultra-550b-a55b`.
4. Prompt it: "You are a quant analyst. Here is the data: {data}. Write a 3-sentence thesis on why this is a good entry, and what the biggest risk is. Be concise and professional."
5. Return the LLM text and attach it to the Signal.

### SECTION 7: THE BACKTEST ENGINE (core/backtest.py)
1. Takes a symbol, a timeframe, and a date range.
2. Iterates through the data candle-by-candle.
3. Simulates entries, exits, stop-losses, and take-profits. Include slippage (0.1%) and exchange fees (0.1%).
4. Calculates: Total Return %, Win Rate %, Max Drawdown %, Sharpe Ratio, Total Trades.
5. Output a summary table and a matplotlib chart showing the equity curve vs. Buy & Hold.

### SECTION 8: THE SELF-IMPROVEMENT LOOP
1. If the backtest Win Rate is < 55% or Max Drawdown > 10%, trigger an optimization loop.
2. Write a Grid Search function that tests different RSI thresholds and EMA periods.
3. Run the backtest for every combination.
4. Save the best performing parameters to `config.json`.
5. Run this loop up to 5 times until the strategy is profitable.
